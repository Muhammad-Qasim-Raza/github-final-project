# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based calculator that calculates simple interest based on the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

The calculator requires the following inputs:

- Principal amount
- Rate of interest
- Time period

## Output

The calculator calculates and displays the simple interest based on the values entered by the user.

## Usage

Run the Bash script in a terminal and enter the principal amount, rate of interest, and time period when prompted.

## Project Files

- `simple-interest.sh` - Bash script for calculating simple interest.
